# Medi-Minder

Medi-Minder is a Flutter-based healthcare and wellness application designed to help users manage important daily health routines from one convenient place. The app supports medication awareness, personal health monitoring, hydration tracking, and simple physical wellness activities through a clean and user-friendly interface.

## Problem Statement

Many people find it difficult to maintain consistent health routines in their busy daily lives. Missed medicines, insufficient water intake, limited awareness of body measurements, and a lack of accessible exercise guidance can negatively affect overall wellbeing. Keeping track of these activities across different notes, applications, or memory alone can also be inconvenient and unreliable.

Medi-Minder addresses this problem by bringing several everyday health-management tools together in one simple mobile application.

## Proposed Solution

Medi-Minder provides users with a centralized wellness companion for organizing and monitoring daily health habits. Users can use the app to remember medicines, calculate and monitor BMI, record water intake, and explore basic yoga exercises. By combining these features in a simple interface, the application encourages users to build healthier and more consistent routines.

The application is intended to support general wellness and routine management. It does not replace professional medical advice, diagnosis, or treatment.

## Objectives

- Help users remember and manage their medicine routines.
- Encourage users to monitor their BMI and understand basic health measurements.
- Promote regular water consumption through daily intake tracking.
- Provide simple yoga exercises for movement, relaxation, and flexibility.
- Make everyday health-management features easy to access and use.
- Encourage consistency in healthy daily habits.

## Features

### Medicine Reminders

Users can set and manage reminders to help them take medicines on time and reduce the possibility of missing important doses.

### BMI Monitoring

The app enables users to calculate their Body Mass Index using basic body measurements and monitor this information as part of their personal wellness routine.

### Water Intake Tracking

Users can record their daily water consumption and use the tracker to develop better hydration habits.

### Yoga and Exercise Guidance

Medi-Minder provides access to simple yoga and exercise resources, including breathing and movement activities that can support relaxation and general wellbeing.

### Simple User Experience

The application brings its health tools together through a clean, approachable interface intended to make regular use straightforward.

## Benefits

- Helps users build awareness of their daily health habits.

## Getting Started

### Prerequisites

- Flutter SDK 3.8.0 or later
- Dart SDK compatible with the installed Flutter version
- Android emulator, iOS simulator, or a physical device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Swathikandula01/medi-minder.git
   ```

2. Open the project directory:

   ```bash
   cd medi-minder
   ```

3. Install the project dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
