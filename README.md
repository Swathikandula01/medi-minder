# Medi-Minder

Medi-Minder is a Flutter healthcare application designed to help users manage their daily health routines with ease. It brings essential wellness tools together in one clean and user-friendly app, helping users stay consistent with medication, hydration, fitness, and other healthy habits.

## Features

- **Medicine reminders** — Set reminders to help you take medicines on time.
- **BMI monitoring** — Calculate and monitor your Body Mass Index.
- **Water intake tracking** — Keep track of your daily water consumption and build healthier hydration habits.
- **Yoga exercises** — Access simple yoga exercises to support movement, relaxation, and general wellbeing.
- **Clean and accessible interface** — Navigate health tools through a simple, approachable design.

## Built With

- [Flutter](https://flutter.dev/)
- [Dart](https://dart.dev/)
- Material Design

## Getting Started

### Prerequisites

Install the following before running the project:

- Flutter SDK 3.8.0 or later
- Dart SDK compatible with Flutter
- An Android emulator, iOS simulator, or physical device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Swathikandula01/medi-minder.git
   ```

2. Move into the project directory:

   ```bash
   cd medi-minder
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## Project Structure

- `lib/` — Application source code
- `assets/` — Yoga and exercise resources
- `android/` — Android platform configuration
- `ios/` — iOS platform configuration
